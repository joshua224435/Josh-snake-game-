# Snake Game

A simple and classic **Snake Game** built with **HTML, CSS, and JavaScript**.

## How to Play

- Use your **arrow keys** to control the snake:
  - `↑` Up
  - `↓` Down
  - `←` Left
  - `→` Right
- Eat the red squares (food) to grow.
- Avoid colliding with the wall or your own body.
- Game ends when the snake crashes.

## Features

- Responsive keyboard controls
- Score tracking
- Simple game over logic

## Files Included

- `index.html` – The main HTML file.
- `style.css` – Basic styling for the game.
- `script.js` – Contains all the game logic.
- `README.md` – This file.

## How to Run Locally

1. Download or clone this repository.
2. Open the `index.html` file in your browser.
3. Start playing!

## Optional: Host on GitHub Pages

1. Push the project to your GitHub repository.
2. Go to **Settings** > **Pages**.
3. Set the source to the root of the `main` branch.
